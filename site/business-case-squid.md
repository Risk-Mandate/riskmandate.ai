# Squid, by the risk it changes

A forward proxy that can act as an allow-list for outbound web traffic. With no access lines it denies, and destinations can be allowed by domain. Written as an answer, the agent reaches the domains on the list.

**Open source:** GPL-2.0-or-later · Squid Software Foundation · [get involved](https://www.squid-cache.org/Support/)

## Every product is also a new thing in the estate.

It sits in the request path. Its documentation also states a default worth reading twice: _If none of the "access" lines cause a match, the default is the opposite of the last line in the list. If the last line was deny, the default is allow._

## What adopting it takes, before any of this is true.

An open-source project costs nothing to download and something to adopt. Every change above depends on the work below, and most of it is customisation to your own deployment.

- Write the domain list for the agent, and end it with an explicit deny.
- Block direct egress at the network, or the proxy is optional.
- Keep the configuration out of the agent's grant.

## The limits of the case, stated by the case.

- That it was tested. Nothing was installed or run; every change rests on the documentation quoted beside it.
- That the register is complete. It is one model, for one stated deployment. A different deployment changes the answers, and so the case.
