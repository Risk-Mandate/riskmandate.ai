Versions

Version record. Every change, and the file it lives in.

Every change to this site ships as a versioned release. The index is versions/index.json and each release's notes are one markdown file beside it — this page renders those files and nothing else, and every entry links to the bytes it was rendered from. Releases up to v0.14.0 were authored in the SG/Vault this site used to be published from; they are carried here as a record and marked as reconstructed, because the builds they describe no longer exist in this repository.
