## The business case for Topgent

The author of [Topgent](https://github.com/farikonsec/topgent), an open-source tool that lists
the AI agents on a machine and what each can reach, asked the lead where to take it. The lead's
note is [D25](briefs.html): make the case, because a run collects much of what an ABP's first pass
needs; explain it from the buyer's desk; and say how to commercialise it. Published, because the
project is open source; built from the repository's pages only, read on 25 September 2026.

- **[The case](business-case-topgent.html)**, computed like the others. Six things it does in
  its own words. Four answers it changes for a coding agent on a developer's machine: what the
  agent could reach becomes a list rather than a shrug; what it did last Tuesday becomes partly
  reconstructable, as metadata; stopping it becomes one command, in minutes, a setting rather
  than a boundary because the same account can stop the sensor first, which its threat model says.
  The register before and after. What it adds: a report on disk that describes the host, an
  optional capture helper, unsigned binaries, and a score this case does not use. What adopting
  it takes. One place its pages disagree, on Windows reachability. What the case does not claim.
- **What a run gives an ABP**, object by object: the grant, measured on a machine the deployer is
  entitled to run, in the ABP's vocabulary and with the evidence kind on each row; the mandate,
  which it cannot know and the person supplies; the delta, arithmetic; the barrier, which starts
  at none for every row, honestly; provenance, from its chained and signed evidence. A
  Topgent-fed ABP would be the first for the agents on a laptop, and the first measured row by row.
- **From the buyer's desk**: a figure of what a run produces and who reads each part, and five
  points a person who signs would want. The generator now draws such a figure from a case's data.
- **Seven notes on taking it to market**, from this site and open-source.sgit.ai: sell the
  maintained build; packaging, not open core, with the one-question test; the buyer is the
  person who signs and the product for them is the ABP; a vault per machine in sgit.ai, the
  pattern this site's own policies use, as the custom UI and the data store without a server; put
  the mandate on the screen so it stops feeling like a network analyser; start from OWASP and the
  summits; and what not to do.
- A new category, host-level agent inventory and stop, computed like the other twelve.

What was not done: a Topgent-fed ABP, because no run was made; the reply to the author, which is
the lead's; and the two screenshots, which are a private conversation and are not archived.
