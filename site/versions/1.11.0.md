## Lab 07, the first behaviour-policy vault

The Lab gets its first entry that is built rather than drawn. **[Lab 07 — what you are
actually buying](lab-vault-delivered.html)** is an Agent Behaviour Policy delivered as a vault,
for the deployment shape this site is maintained from: Claude Code on the web, with one
repository attached.

**Eight files from three inputs, and one of the three is yours.** The grant is the published,
measured profile for the shape (13 of 20 rows observed on the thing itself), the vocabulary
is copied in and pinned at abp.sgit.ai v0.3.0, and the mandate is the only file a person
writes. Everything else — `AGENT-BEHAVIOUR-POLICY.md`, `GRANT.md`, `DELTA.md`,
`LICENCE-TO-OPERATE.md`, `README.md`, `data/delta.json`, `data/validity.json` and a history
entry per recompute — is derived by `scripts/site/build-abp-vault.mjs` on every run, so a
hand edit to any of them does not survive. The build recomputes the delta and refuses to
write if it cannot reproduce the record the model site published; it can, row for row. CI
now runs that check as a gate.

**Two generic files travel with every vault unchanged.** `AGENTS.md` is the drop-in for the
agent's own context — a `CLAUDE.md`, an `AGENTS.md`, a role file, a skill — and says what the
other files are, what to do with them, and, in its own words, that it is a rule in prose and
bounds nothing. `SKILL.md` is the same in the portable agent-skill format, with the format's
limit stated on its face. Both live in `site/vaults/_template/`.

**Licence to Operate gets a referent.** The organisation is the authority, the behaviour
policy is the instrument, the agent is the licensee. The document carries scope, nine
conditions each beside what enforces it (for six of them: nothing), an interval, and a
signature line. No word about cover, and *mandate to operate* is retired.

**A grant check, from inside the shape.** The session that built the vault read the grant
back against what it had actually done in the course of the work: eleven of fifteen rows seen
present, none absent, four not re-checked, the credential row deliberately. Two probe batches
it proposed were refused by the platform's action classifier before they ran, which the check
records as a barrier the grant has no row for.

**The vault is pushed** (`ruj286tr`, one commit). Its read key stays off the page until the
owner confirms it is public, for the same reason one demo key already is; every file is served
from `site/vaults/claude-code-web/` regardless, so nothing on the page depends on the vault host.

concepts against the workflow that sells a behaviour policy, three days before Lisbon.
