# v1.38.4 — Review feedback: clearer choices, a send on every box, and screenshots

9 October 2026. The lead's first feedback through the review lane, read the same day, asked for three
changes to the review page. This release makes them and changes nothing else on the site.

- **The choice on each changed section says what it means.** *A · now reads better* read as if A had been
  changed too. The buttons now read *B · is good (proposed)*, first and marked as the one to find, then
  *A · was better (current)*, then *No difference to me*.
- **Every comment box sends itself.** Each has a *Send this comment* button and a line saying whether what is
  in it has gone. It also sends when the reader leaves the box, and after eight quiet seconds of typing. The
  page-wide *Send feedback* and the two-minute send are unchanged.
- **Screenshots, by paste or drop.** Any comment box takes an image. It is shrunk in the browser to 1,600
  pixels on the long side, shown as a thumbnail that can be removed, kept in the browser, and encrypted with
  the next send, two to a message. `scripts/review/read-feedback.mjs` writes each one into the vault beside
  its record as an image file, and keeps the record itself free of the image data.
- **Tested in a browser with the lane stubbed,** at desktop and phone widths: the labels, a send on leaving a
  box, on the button and after a pause, and a pasted screenshot that arrives in the record and is marked sent.

What was not done: no live send was made for this release; the lane and vault are the ones tested end to end
in v1.38.3. The vault key went to the lead's key registry, sealed to its published key on a write-only lane,
so it no longer needs copying from the chat; the registry's acceptance is visible only to its owner.
