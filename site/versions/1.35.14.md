# v1.35.14 — The next home page, as an experiment beside the current one

2 October 2026. The lead sent a new home page as a React component, `RiskMandateHome.tsx`, by voice: *I really like
the animation; refactor it so it does not use React, be as exact as you can, in our current environment; do not lose
the current home page; put the current one on another page linked from the top, and the new one as an experiment
page; once we have it right, replace the home page and delete the experimental page.*

- **The experiment is `home-next.html`**, in More, marked private (noindex, no twin, disallowed in robots) because it
  is a page to look at rather than one to publish. It sits in the site's chrome, the shared header and footer, and
  between them is the mock, ported line for line: the mock's own CSS, scoped under one class so it touches nothing
  else; the stage with six agents, the gate and the four kinds of dot travelling the lanes, which was always pure CSS
  keyframes and needed no framework; and the four interactive parts, the system picker, the rules with their four
  actions, the alert toggles and the price builder, re-rendered from one plain state object by a script of sixty
  lines. No React, no build step, no dependency. The page has no console errors at desktop or phone width.
- **The current home page is copied to `home-current.html`**, private, in the same group, so the two can be opened
  side by side. It is a copy of `index.html` as it stood at v1.35.13 and says so in a comment; when the home page
  changes, it is recopied rather than edited. `index.html` is untouched: the site's home page is the same today as it
  was yesterday.
- **The review, since the lead asked for one.** The design is good and the port keeps it. The words are another matter,
  and they are flagged on the page itself in a note at the top rather than silently rewritten: the mock sells an
  enforcement product, real-time enforcement, alerts by text and email, per-system subscriptions in dollars, a
  tamper-evident decision log, none of which the site sells; a behaviour policy on this site describes an agent, and
  what the store sells is the four levels on the pricing page. The mock says *policy* alone throughout, which this
  site's rule 3 avoids because *policy* is also the insurance instrument in the Licence to Operate demo. Its prices
  are illustrative, in dollars, with no provenance. It had five dead links, now pointed at the contact page. Its
  spelling was American and is now British. It names Gmail, Google Workspace and the rest only as systems, with no
  verdict on any. Nothing on it is scored. None of this is a reason not to look at it; it is the list of what has to
  be decided before it can be the home page.
- **What it took.** A converter in the session's scratchpad turns the JSX to HTML: inline style objects to style
  attributes, SVG attributes to their real names, self-closing spans to pairs, the five rendered lists to containers
  the script fills. The output is then a hand-authored page in the tree, like the home page itself since v1.26.0.

Not done: the mock's font, Geist, is not loaded, so the page sets in the system sans like the rest of the site; the
mock's own header and footer are replaced by the site's; and nothing on the page is wired to a store or a form,
because nothing on it is a product the site sells yet.
