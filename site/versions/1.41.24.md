# v1.41.24: A measured template for Odoo 20 Community, built and waiting for its push

19 November 2026.

- **A new template vault, `odoo-bills-integration-user`, is built and checked.** It describes an agent
  holding the API key of a narrow integration user on a self-hosted Odoo 20 Community database, there to turn
  supplier documents into draft vendor bills. All seven rows are measured, on an Odoo 20.0-20261112 Community
  instance we stood up and ran ourselves on 16 November and tore down the same day; the session record, 25 calls
  and their answers, is in the vault's `history/`. Posting a bill, paying, creating a supplier and widening its own
  access are out of reach. Editing a draft after approval, emailing a supplier from a bill's chatter, scheduling a
  message, attaching files and reading every supplier bank account are in it, most of them through Odoo's default
  internal-user role rather than the group made for the job. The starting mandate wants four rows; the delta has
  three in excess, all refused, none bounded. Two contradictions between Odoo's own pages are published unresolved,
  and four questions are left open, among them what Odoo's AI agents and MCP server would add on Enterprise.
- **Unpushed means unpublished, everywhere.** The workflow already said a catalogue entry without a vault id and a
  read key is built and unpushed. The library honoured that; the home page count test, the
  [rules](rules/index.html) coverage, the pitch deck's shape count and the admin console did not, and would have
  counted the new vault as published before anyone could open it. Each now counts pushed entries only, and the
  console links an unpushed vault to its folder and says so.

What was not done. The vault is not pushed to sgit: that takes the lead's key, and until then it has no library
page, no tile and no place in any count, and the home page still says sixteen. Odoo's AI agents and MCP server were
not run, because they are Enterprise modules; nothing on the page claims they were. No other vault, page or renderer
changed beyond the regenerated logo map.
