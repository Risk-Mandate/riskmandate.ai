## Unified menu component + pricing update

- **One menu, everywhere.** The header nav is now built by a single shared component (`rm-menu`) on every page — version sites and top-level pages alike. It renders the in-page section links (inlined per version from `menu.json`) followed by the top-level page links (Partners, Dev), marking the current page active. Replaces the previous split between hardcoded section buttons and a separate page-nav.
- **Pricing** on v0.4 is now three options: **Free**, **Consumption** (token-based, metered by usage), and **Enterprise** at **$5K–15K per month**.
