## The homepage leads with the policy, and says which rung we are on

The front page sold a measurement product and hid the one we can actually deliver. It now leads
with the Agent Behaviour Policy and keeps insurability as the destination, which is both the honest
order and the stronger argument: **you cannot insure what nobody can describe.**

**The site was contradicting itself, and that is fixed first.** Three places on the homepage claimed
an environment-discovery capability we do not have and explicitly disclaim elsewhere — *"derived
from your environment through read-only connectors, never from a self-assessment"*, *"agent
discovery and blast-radius measurement through read-only connectors"*, and, in the comparison
against questionnaires, *"read-only connectors derive what each agent can actually reach"*. Against
that, [Questions](questions.html#q3) says plainly: *"an inventory built on telemetry sees what is on
the network whether anybody admits to it or not. We do not — this reaches a personal device, a
personal account and a locally run server with no install and no administrator, and in exchange it
only ever sees what somebody is willing to say."* Both were live. The Questions page is the true
one, and it is also the better story, so all three now describe deriving the grant from the
deployment shape. The contrast with a questionnaire was never that we measure and they do not; it
is that the unit of the answer is a capability with a barrier against it rather than a yes or a no.

**[What we sell](index.html#policy), new, and the section the page did not have.** The four objects
with the verb on each, the note that a policy is a draft meant to be argued with, and the five files
it is delivered as. The primary call to action is now the [policy page](abp.html) rather than an
Index nothing computes.

**[Where this goes](index.html#ladder), new.** The grounding ladder that has been on
[the model page](abp.html) all along, which the homepage never told: the label, then the twin, then
the Index and the acceptance. Each rung needs the one below it. Rung one is marked *what we sell*;
rungs two and three are marked *design*. **We are on the first, and the page says so.**

**The Index keeps its six levels and its five dimensions**, restated as the published design for
rung three rather than as a running calculation — *published before it is built on purpose, so the
commitment stays checkable afterwards*. The acceptance workflow gets the same treatment: a named
person, a stated period, and implementation not claimed. Nothing was deleted and no ambition was
dropped; what changed is that each part now says where it stands.

**The closing panel no longer asks anyone to know a number.** It asks them to start with one agent
they already run. The header button on this page and on the model page said *Get your Index* and now
says what it does, which is open a conversation.

No price anywhere on the homepage. The entry tier exists but the route to it is not wired up
properly yet, and a buy button that leads somewhere unfinished is worse than a link to the page that
explains what is being bought.
