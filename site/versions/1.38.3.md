# v1.38.3 — The review feedback gets its own vault

9 October 2026. The lead gave the access token to create a vault for the review page's feedback, so the
answers no longer share the contact form's lane and can be read by whoever holds this vault's key.

- **A new private vault, `ao0lynta` on dev.send.sgraph.ai, with one append lane, `review`.** The private key
  that opens what arrives is kept in the vault, encrypted with a secret derived from the vault's write
  key, so the vault key is the only secret. That key was handed to the lead in the session and is in no file.
- **`site/assets/review/lane.json`, public by design:** the vault id, the lane's write-only token, the public
  key and its fingerprint. The token can only write; the key can only encrypt.
- **The review page sends there.** It checks the key against its fingerprint, encrypts each send in the
  browser with the same envelope as the contact form, and appends it. Nothing else on the page changed.
- **`scripts/review/read-feedback.mjs` reads it.** With the vault key in the environment it lists the lane,
  decrypts each send, files it in the vault as an email and a JSON record, marks it processed, and prints
  every answer and comment per reader.
- **Tested end to end:** one labelled message sent from the page, accepted by the server, decrypted by the
  reader and filed in the vault on 9 October.

The contact form and the comms vault are unchanged; the drain change of v1.38.2 is undone, because review
messages no longer go there.
