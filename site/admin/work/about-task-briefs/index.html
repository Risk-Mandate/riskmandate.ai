Task briefs — written to be picked up by one agent each

The rules that are not optional, read automatically by Claude Code. The source is .claude/briefs/README.md; this page is that file, rendered.

Each brief is a unit of work sized for one branch, with the files it touches named so two agents can see at a glance whether they would collide. Read ../onboarding/04-rules-of-engagement.md before claiming one, then write your .claude/work/<branch>.md naming the brief.
