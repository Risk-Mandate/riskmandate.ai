# The mark is a seal.

RiskMandate produces a record somebody puts their name to. The mark says that before a word is read: a stamp with a monogram inside it, registration ticks on the axes, and a quiet inner ring. It signals counter-signature and provenance to the audiences that matter — underwriters, risk committees, boards.

## One mark, three fidelities.

The containered mark is the default. The knockout drops the container for dark surfaces where a filled tile would sit heavily. Below 24px the detail genuinely dies — so there is a simplified cut rather than a blurred one.

## Five things not to do.

### Do not recolour it

The green is `#1A7F5A` and the container is `#161615`. The mark never appears in another hue, and never in full colour on a coloured field.

### Do not use the detailed cut below 24px

The registration ticks and the inner ring turn to mud. Use the simplified mark, which keeps the ring and the monogram only.

### Do not stretch, rotate or add effects

No drop shadows, no gradients, no outer glow. A seal that looks printed is doing its job.

### Do not redraw the monogram

RM is set in the mono face at a fixed optical size inside the ring. It is not a text layer to be re-typeset.

### Do not crowd it

Leave clear space of at least half the mark's width on every side. In a UI bar that means the mark, a gap, then the wordmark.

## Ink, green, warm greys.

Every colour in the product is a token. Nothing is a literal hex outside the token block — the same rule the code follows.

## System faces, deliberately.

No web fonts, no CDN, no flash of unstyled text, and nothing to load before the page is readable. The system sans carries everything; the system mono carries labels, keys, numbers and anything that should read as machine output.
