# LangGraph and LangChain human-in-the-loop, by the risk it changes

Middleware that checks each tool call against a policy and, when intervention is needed, interrupts execution until a person responds. Written as an answer, the agent changes things with a person approving each change, for the tools configured.

**Open source:** MIT · LangChain (company-maintained) · [get involved](https://forum.langchain.com/)

**The deployment:** The model's typical deployment, with the answers this project addresses stated as they are without it: it changes things on its own.

**The model:** the RiskGraph Explorer's 49 facts, 49 risks and 10 roles, copied into this site with its provenance; the register below is computed, not written. [How](business-cases.html#method).

## Every product is also a new thing in the estate.

Its interrupts page says the runtime restarts the entire node from the beginning when it resumes, so any code that ran before the interrupt runs again, which matters if that code changed something.

## What adopting it takes, before any of this is true.

An open-source project costs nothing to download and something to adopt. Every change above depends on the work below, and most of it is customisation to your own deployment.

- Choose the tools that must wait, and show the person what the call will do.
- Make the code before an interrupt safe to run twice.
